# 摘要范围内的初步评审

材料仅包括题为 *Universal Tabular Learning with Adaptive Features* 的合成摘要，版本未注明；正文、表格、附录、代码和数据说明均未提供。以下审查贡献表述和证据范围，不据此认定完整论文没有做某项实验。未进行外部检索或独立复现，创新性尚未外部核查。

作者提出用于表格分类的 adaptive feature module，并报告十二个数据集上的平均 accuracy 提高三个**百分点**。多数据集比较有可能支持一定范围的经验有效性，但当前只有汇总叙述，无法判断比较协议、结果稳定性或模块本身的增量贡献；“所有表格领域均有稳健提升”的范围尤其超出了摘要可展示的证据。

| ID／作者主张及定位 | 实验直接证据／理论依据 | 合理推断及前提 | 未验证部分／支持程度 |
|---|---|---|---|
| C1：提出 adaptive feature module（摘要前两句） | 摘要描述了模块用途；未给出结构、公式或理论 | 可能是表格分类的建模贡献，具体机制尚不可判断 | 与最相关方法的区别及创新程度：无法判断 |
| C2：十二个数据集平均提升三个百分点（摘要第三句） | 摘要报告一个汇总数值；没有可核查的逐数据集结果或实验协议 | 若同一划分、适当基线与比较预算成立，可支持这些任务上的平均提升 | 数据集、基线、重复次数、平均方式和不确定性：无法判断 |
| C3：所有表格领域均有稳健收益（摘要末句） | 当前材料没有展示领域覆盖或稳定性结果；无适用理论依据 | 十二个数据集的均值不能推出所有领域均受益，也不能保证每个数据集受益 | 普遍外推：现有材料证据不足；完整论文是否另有支持未知 |
| C4：额外计算很少（摘要末句） | 没有训练／推理成本数值 | 需明确“很少”的成本维度和比较条件后才能解释 | 参数量、运行时间、硬件与计时范围：无法判断 |

决定当前评价的三个待补证问题是：

- **R1（关联 C2，影响高，批评置信度高）**：摘要的平均值隐藏任务差异。需要相关实验表、数据划分和基线协议，检查逐数据集效应、平均权重与同一测试样本上的比较；目前无法断言结果不公平或不稳定。
- **R2（关联 C1、C3，影响高，批评置信度高）**：材料没有说明模块如何产生收益，也不足以支撑普遍范围。提供机制说明及匹配数据、模型容量和调参预算的模块控制比较，才能区分模块贡献与额外资源的作用；也可将结论收窄至已评价的任务。
- **R3（关联 C4，影响中，批评置信度高）**：成本主张未量化。提供相同环境下训练与推理的增量成本、计时边界和目标精度即可核查，无需泛化为所有部署场景。

最小下一步是取得这些主张对应的实验设置、主要结果表和必要模块对照，而不是先要求大规模新实验。若已有结果显示多个任务均稳定受益且预算匹配，可提高对 C2 的支持；若收益集中于少数任务，应调整 C3 的范围。当前能确认的是作者的贡献与结果表述，不能确认实验可信度、首创性或普遍优势。
