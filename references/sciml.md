# SciML 专项检查

围绕论文的科学主张选择适用项目，不因未做无关检查而扣分。

- **问题设定**：核对 PDE/ODE、系数、单位/无量纲化、区域、初始和边界条件、观测噪声与采样协议；分清正问题、逆问题与数据驱动代理。
- **参考解**：核对数值解的网格/时间步收敛、容差、离散误差和求解器可靠性。称其为参考解；仅有高分辨率模拟不等于精确真值。
- **物理有效性**：分别检查方程残差、解误差、守恒、边界一致性、稳定性和任务相关物理量。小残差并不自动保证小解误差或唯一解；说明是否有稳定性或误差界支撑。核对残差是否在独立于训练配点的区域评估，误差范数、积分权重和采样密度是否一致，避免稀疏采点掩盖局部失败。
- **泛化层次**：区分同一轨迹采样、新初值/边界、新系数、新几何、跨分辨率和长时间滚动外推。核对测试参数是否落在训练范围内、训练与测试轨迹是否独立。分清单一实例拟合与跨实例算子学习，逐实例重新训练的成本必须纳入相应声称；长时间预测区分 teacher forcing 与自由滚动。
- **逆问题**：检查可辨识性、观测充分性、正则化、先验依赖和噪声敏感性；拟合观测不等于恢复真实参数。
- **公平成本**：比较合适的经典数值求解器及相关学习方法，核对目标精度、硬件、并行度、预处理和计时边界；分别报告数据生成、训练、单次推理与多次查询的摊销成本。加速结论需匹配精度与使用场景。
- **模型与数值细节**：检查自动微分精度、配点分布、损失权重、尺度差异、刚性、高频、边界层、误差随时间积累；依据实际问题选择检查。
- **不确定性**：区分数据噪声、参数不确定性、模型误差、离散误差与评审者信息缺口；若声称可靠 UQ，检查覆盖率、校准和分布变化下表现。
